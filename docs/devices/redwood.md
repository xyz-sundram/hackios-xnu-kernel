# Upstream Redwood reference

The POCO X5 Pro 5G (`redwood`) is an upstream SM7325 reference device. Its earlier
hardware results do not establish support on Nothing Phone (1).

This fork's active device is [Nothing Phone (1)](spacewar.md), with
[Phone (1) status](../spacewar-status.md) and a local source port under
`devices/spacewar/`. The upstream reference source remains in
[hakios-sm7325](https://github.com/oosexgang/hakios-sm7325).

Historical engineering reports retain their recorded device names and measurements.
This page intentionally carries no inherited working-feature table for Phone (1).
