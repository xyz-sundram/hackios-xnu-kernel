# Двойная загрузка на Nothing Phone (1)

Порт U-Boot для **Nothing Phone (1)** (`spacewar`, SM7325) разрабатывается.
Полная цепочка U-Boot → EFI-загрузчик → XNU → iOS проверена на телефоне:
графика работает на 550 МГц, пользователь подтвердил сенсорный ввод, громкость
и отсутствие текста журнала в тихом варианте с отключённой отладкой.
Mu-Silicium остаётся отдельным проверенным вариантом запуска из RAM. Установка
второй системы и сохранение данных между запусками ещё не подтверждены.

## Текущее состояние

- Исходники U-Boot v2026.07 с деревом устройств и окружением Spacewar собираются.
- Первые RAM-тесты остановились на логотипе Nothing. Проверка ELF выявила
  ошибочное размещение BSS поверх стартового кода при сборке LLD.
- Исправление компоновки применено. Диагностический вариант с `stdin=nulldev`
  запустил USB fastboot на телефоне; журнал консоли получен.
- Для возврата в штатный fastboot нужны аппаратные кнопки. Программный переход
  в загрузчик Android в текущих RAM-профилях не поддерживается;
  `reset bootloader` только перезапускает телефон.
- После исправления порядка инициализации консоли меню появилось на телефоне;
  навигация кнопками громкости и питания работает. Выбор пункта USB fastboot
  физическими кнопками также проверен, журнал консоли получен.
- В исправлении назначение консольного ввода отложено до `jumptable_init`:
  прежний код обращался к ещё не созданной таблице `gd->jt`.
- В текущем тихом варианте меню стартовая трассировка отключена.
- Отдельный профиль `storage` выполняет проверку UFS/SCSI без записи, затем
  запускает USB fastboot. USB работает, но поиск накопителя возвращает `-6`,
  в том числе после исправления опорной частоты.
- Полный запуск iOS из RAM через U-Boot проверен с графикой 550 МГц, сенсорным
  вводом и громкостью. Исправлена передача состояния IRQ слота RSC под исключительной
  арендой загрузчика; прошивка сенсора загружена в RAM контроллера с совпавшей ECC
  `0x22ed` и проверкой рабочего режима/версии.
- Загрузка с накопителя и постоянная установка не подтверждены. Записи в разделы
  в этих тестах не выполнялись.
- В тихом повторном запуске использованы `hakios_debug=0` и отключённый вывод
  состояния/отладки USB прошивки. Устойчивое чтение live-журнала в этом запуске
  не подтверждено: первый снимок не получен за 60 секунд. USB и полная консоль
  проверены в диагностических запусках.

Актуальные команды сборки RAM-образа и журнал проверки находятся на
[английской странице](../dual-boot.md). Полная сборка проверенного варианта
Mu-Silicium описана в [корневом README](../../README.md#build-for-nothing-phone-1-spacewar).

## Установка пока не готова

Следующие проверки — обнаружение накопителя, загрузка с него и полный возврат
в Android. Затем необходимы проверенные резервные копии и план разделов именно
этого телефона.

Размер раздела `darwin`, размещение Android в слоте b и постоянный том данных
на 12 ГБ не являются установленными фактами для Phone (1). Команды прошивки,
переразметки и стирания из прежней инструкции относятся к другому устройству;
на этой странице они не предлагаются как инструкция для Spacewar.

RAM-тест запускается из штатного fastboot командой `fastboot boot` и не меняет
активный слот. Для возврата используйте аппаратные кнопки, чтобы войти в штатный
fastboot, затем `fastboot reboot` для запуска существующего Android.

[Состояние Phone (1)](../spacewar-status.md) отделяет проверенные возможности
этого телефона от исторических результатов других устройств.
