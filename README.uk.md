# HakiOS: Nothing Phone (1)

Ця гілка призначена для Nothing Phone (1), `spacewar`, Snapdragon 778G+ / SM7325.

На телефоні перевірено домашній екран і шпалери, одноточковий дотик, кнопки живлення
й гучності, сім ядер XNU, USB-завантажувач на CPU0 та графіку Adreno 642L через
Mesa/OpenGL ES на 550 МГц. Запити частот великих ядер — близько 1900/1862 МГц.
Тихий режим зберігає налагоджувальний код; автоматичного обмеження часу немає.

Мультитач і тривала стабільність не перевірені. Аудіо, Wi-Fi, камери, вібрація,
показ заряду, заряджання, стільниковий зв'язок і збереження даних між стартами
не підтверджені на цьому телефоні. Результати інших пристроїв сюди не переносяться.
